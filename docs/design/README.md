# 运营平台页面设计

本目录保存 English Room 私有运营平台的首轮高保真设计图。桌面端用于完整运营工作台，移动端总览用于验证 App WebView 内的响应式体验。

## 页面清单

| 页面 | 文件 | 核心能力 |
| --- | --- | --- |
| 运营总览 | [`01-overview.png`](./mockups/01-overview.png) | DAU、增长、留存、转化漏斗和系统状态 |
| 稳定性中心 | [`02-stability.png`](./mockups/02-stability.png) | 崩溃、Issue、受影响用户、版本和设备分布 |
| 房间监控 | [`03-rooms.png`](./mockups/03-rooms.png) | 实时房间、成员媒体状态、生命周期和受控结束 |
| 评分任务 | [`04-scoring-jobs.png`](./mockups/04-scoring-jobs.png) | 任务队列、玩家音频关联、失败原因和受控重试 |
| 审计日志 | [`05-audit-log.png`](./mockups/05-audit-log.png) | 管理员操作、请求结果、风险等级和变更摘要 |
| WebView 移动端总览 | [`06-mobile-overview-webview.png`](./mockups/06-mobile-overview-webview.png) | 在内部 App 中查看核心指标和系统状态 |

## 设计原则

- 与 App 共用深墨绿、薄荷绿和暖白色品牌体系，但采用更高的信息密度。
- 桌面端使用固定侧边栏；移动端 WebView 使用顶部环境栏和底部导航。
- 总览回答“业务是否增长”，稳定性回答“用户是否受影响”，房间和评分页面回答“具体任务在哪里异常”。
- 重试评分、结束房间等写操作必须显示风险状态，并在 FastAPI 服务端执行 RBAC、幂等和审计。
- Sentry 管理 Token、腾讯云密钥、完整音频地址和长期访问令牌不得出现在页面数据中。
- 图中的数据和身份均为设计示例，不代表真实生产数据。

## 响应式约定

- 桌面基准画布约为 `1568 × 1003`。
- 移动端 WebView 基准画布约为 `863 × 1822`。
- 移动端卡片自然纵向排列，不允许依赖横向滚动查看关键指标。
- 触控目标不小于 44 点，图表应同时提供可访问的文字摘要。
